Practice

Try Procyon without a radio: simulated stations call CQ and answer you. Nothing goes on the air, and demo QSOs go into a separate practice log that only exports as plain text. Always off when Procyon starts, so it's never left on by mistake.

Clock

FT8 and FT4 need your clock within about a second. Band sync times Procyon by the stations it hears (the middle value of their time offsets, once 8 or more are heard), so it works in the field without internet or GPS. It only shifts Procyon's own timing; your computer's clock isn't changed. A clock more than about 2 s off decodes nothing to sync to - set it once by hand. The correction starts from zero each time Procyon starts.

Decoder

Procyon decodes FT8 and FT4 itself, with its built-in decoder, tpdec. WSJT-X's decoder is there as a fallback, for comparing or if something seems wrong; it's offered only when WSJT-X is installed. The change takes effect from the next cycle.

When Procyon's page is closed

So it doesn't keep running unseen, holding the radio and sound card. Tabs on other devices (remote access) count as open; a page reload doesn't count as closing. Whatever this is set to, transmitting always stops 10 seconds after the last tab closes.

New versions

Once a day Procyon asks GitHub (where it's published) for the newest version number, and shows a message at the top of the screen when there is one. Nothing about you, your station or your log is sent. Without internet it just stays quiet.

Logbook export

For importing into another logging program (e.g. N3FJP): each export then holds only the QSOs logged since the last one, so the same QSO is never imported twice. The Export button shows how many are new. Press Save to switch it on or off.

Download the whole log (ADIF)

Switching it on for the first time and your logging program already has your QSOs? Press "Mark every QSO as already exported" once, so the first export doesn't bring them in again. "Download the whole log" always gives everything, e.g. for a backup.

Logbook import

Bring in the QSOs you made before Procyon, or with other programs, so NEW and "new band" know everyone you've already worked. QSOs already in your log are skipped, so importing twice adds nothing. Your log is backed up first.

Importing can only be done on the computer running Procyon.

"Import from QRZ" downloads your QRZ logbook with the API key from the Logbook tab (downloading needs a QRZ subscription). Without one, export your logbook as an ADIF file on qrz.com, or from WSJT-X or your logging program, and import the file. QSOs from QRZ are marked as already on QRZ, so they're never uploaded again.

Country data

Updating can only be done on the computer running Procyon.

Procyon tells which country a callsign belongs to (and roughly how far away it is, when there's no grid) from Big CTY, a file made by Jim Reisert AD1C and published at country-files.com. A copy comes with Procyon, but it's only as new as your version of Procyon - new DXpeditions and special-event calls are added every few weeks. The button downloads the latest into Procyon's own folder (WSJT-X's copy isn't touched), and Procyon always uses the newest copy it has. Nothing about you is sent. Big CTY © Jim Reisert AD1C, MIT licence.

POTA activation

Operating from a park? Start an activation and every QSO is tagged with the park, your CQ becomes CQ POTA, and Procyon saves a log for each park that you can upload at pota.app.

Leave the grid empty to use your home grid. The state helps pota.app when a park crosses a state line.

Park logs - saved here, for you to upload

Procyon doesn't send these anywhere: when you're ready, sign in at pota.app and upload each file under My Log Uploads. With several parks, the same QSOs go into each park's file - that's how POTA counts them. These QSOs are in your main logbook too, so QRZ uploads include them as usual.
